# alt-history-sim

Een simulator voor alternatieve geschiedenis, geïnspireerd op Europa
Universalis. De wereld begint realistisch in 1444 en schrijft daarna zelf
haar eigen geschiedenis, tot 2026. Je speelt niet mee: je kijkt hoe de
geschiedenis verloopt en leest wat eruit ontstaat.
